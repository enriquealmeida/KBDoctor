## 2026-05-31 - Migracion de dialogos WinForms a formularios HTML

### Formularios HTML para acciones interactivas

- Se agrego `KBDoctorUI/Sources/KBDoctorWebForms.cs`.
- Este helper genera paginas HTML temporales para pedir datos al usuario y luego ejecutar comandos KBDoctor mediante links `gx://`.
- Incluye utilidades para:
  - entradas de texto genericas
  - busqueda y reemplazo
  - reemplazo de dominios
  - seleccion de tabla y atributo
  - menus de acciones
  - pantalla About
  - lectura normalizada de parametros de comandos

### Reemplazo de dialogos WinForms por comandos aplicables

- `AttributesHelper.cs`:
  - `AssignDescriptionToAttribute` ahora muestra un formulario HTML con el valor actual.
  - nuevo `ApplyAttributeText` para aplicar descripcion, titulo o column title.
  - `ReplaceDomain` ahora muestra un formulario HTML con dominios de origen y destino.
  - nuevo `ApplyReplaceDomain` para ejecutar el reemplazo real.
- `TablesHelper.cs`:
  - `AssignDescriptionToTable` ahora muestra un formulario HTML.
  - nuevo `ApplyTableText` para guardar la descripcion de la tabla.
- `CleanKBHelper.cs`:
  - `SearchAndReplace` ahora muestra formulario HTML.
  - nuevo `ApplySearchAndReplace` para ejecutar la busqueda y reemplazo sobre objetos seleccionados.
- `NavigationHelper.cs`:
  - `AttUpdated` ahora muestra seleccion HTML de tabla y atributo.
  - nuevo `ApplyAttUpdated` para ejecutar el reporte con los parametros elegidos.
- `ObjectsHelper.Commands.cs`:
  - `ObjectsUpdatingAttributes` se separo en seleccion y aplicacion.
  - nuevos `SelectObjectsUpdatingAttributes` y `ApplyObjectsUpdatingAttributes`.

### Nuevos comandos y registro del paquete

- Se agregaron claves en `CommandKeys.cs` y handlers en `CommandManager.cs` para las nuevas acciones:
  - `ApplyReplaceDomain`
  - `ApplyAttUpdated`
  - `ApplyAttributeText`
  - `ApplyTableText`
  - `SelectObjectsUpdateAttribute`
  - `ApplyObjectsUpdateAttribute`
  - `SetObjectPropertyText`
  - `ApplyObjectPropertyText`
  - `AssignAttributeOrDomainToVariable`
  - `ApplySearchAndReplace`
  - `RunResponsiveSmoothAction`
- Se actualizaron `KBDoctorUI/KBDoctor.package` y `KBDoctorUI/GeneXusPackage.package` para exponer esos comandos.

### Acciones sobre objetos y variables

- `ObjectsHelper.Commands.cs`:
  - nuevo flujo para editar propiedades de texto de objetos mediante formulario HTML (`SetObjectPropertyText` / `ApplyObjectPropertyText`).
  - nueva accion `AssignAttributeOrDomainToVariable` para asignar atributo o dominio a una variable sin usar el formulario WinForms anterior.
- `ObjectsHelper.Refactoring.cs`:
  - el reporte de variables no basadas en atributo/dominio ahora agrega links accionables por variable.
- `ObjectsHelper.cs`:
  - `CreateDeployUnits` deja de abrir un prompt directo para `AppLocation` y agrega una accion `Set AppLocation` en el reporte.

### Acciones Responsive / Smooth

- Se agrego `KBDoctorUI/Sources/ResponsiveSmoothActions.cs`.
- `BuildObjectWithProperty` ahora abre un menu HTML de acciones.
- Acciones disponibles:
  - convertir propiedades responsive por defecto
  - convertir Web UX por defecto a Smooth
  - mover objetos generados de Previous compatible a Smooth
  - auditar objetos Smooth/Responsive
  - resetear referencias a MasterPage por defecto

### Limpieza de dependencias WinForms

- `KBDoctorUI.csproj` excluye de compilacion formularios WinForms reemplazados o deshabilitados:
  - `AboutBox1`

## 2026-06-02 - WebForm to AbstractEditor

- Se agrego el comando `WebFormToAbstractEditor` para convertir WebPanels seleccionados desde WebForm HTML al Abstract Editor.
- Se registro el comando en:
  - `KBDoctorUI/Sources/CommandKeys.cs`
  - `KBDoctorUI/Sources/CommandManager.cs`
  - `KBDoctorUI/KBDoctor.package`
  - `KBDoctorUI/GeneXusPackage.package`
  - `KBDoctorUI/StringResources.resx`
- Se agrego una entrada de menu `UI-FrontEnd` para ejecutar la conversion desde GeneXus.
- `ObjectsHelper.Commands.cs` agrega la accion `webFormToAbstractEditor` al menu HTML de acciones Responsive/Smooth.
- `ResponsiveSmoothActions.cs` incorpora la logica principal:
  - seleccion multiple de WebPanels.
  - filtro de objetos editables por usuario.
  - reseteo de `MasterPage` y `Theme` a valores por defecto cuando corresponde.
  - conversion del formulario raiz HTML a layout abstracto usando `MultiForm.Layout.ConvertForm`.
  - resolucion previa de referencias almacenadas `att:` y `var:` antes de convertir.
  - reemplazo posterior de referencias por nombres de atributos y variables.
  - sanitizacion de terminadores CDATA invalidos y validacion de XML convertido.
  - soporte para reemplazos de clases mediante `KBDoctorWebFormClassReplacements.csv` en el directorio de usuario de la KB.
  - reporte HTML con objeto, modulo, MasterPage, Style, tipo de editor y resultado de conversion.
  - salida de resumen con seleccionados, guardados, ya abstractos, convertidos, no convertidos y fallidos.
- Se agregaron diagnosticos de conversion para volcar XML intermedio cuando falla la conversion o `EditableToStored`.
